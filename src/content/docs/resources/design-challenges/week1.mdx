Boas-vindas ao primeiro desafio de projeto! Vamos começar com um chassi de tração swerve, a base do seu robô. Temos dois níveis de desafio: iniciante e avançado. Recomendamos completar o desafio iniciante antes de partir para a versão avançada. A versão avançada é a continuação do modelo iniciante, com alguns requisitos extras adicionados.

<Tabs>
  <TabItem label="Desafio Iniciante">
    * Você deve escolher um modelo COTS de módulo swerve
    * A estrutura deve ser montada utilizando tubos de alumínio de 2" x 1"
    * Você deve adicionar uma bellypan (chapa de piso)
    * O chassi deve ser legal e compatível com as regras de campo da FRC
  </TabItem>
  <TabItem label="Desafio Avançado">
    * Fazer o layout e adicionar furações de fixação para toda a eletrônica, garantindo espaço para passagem de cabos
    * Importar os modelos CAD da eletrônica e fazer as montagens com mates
    * Posicionar e fixar a bateria de forma segura e com fácil acesso
    * Adicionar os bumpers (para-choques)
    * Projetar os suportes de montagem dos bumpers
  </TabItem>
</Tabs>
