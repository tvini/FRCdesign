### Subsistemas com Múltiplos Graus de Liberdade

Quando um subsistema possui múltiplos graus de liberdade (partes que se movem de forma independente), a recomendação é dividir as partes móveis em montagens rígidas separadas. Cada conjunto que se move como um corpo único deve formar uma montagem "rígida" (sem folgas nem relações móveis internas), enquanto a montagem de nível superior do subsistema apenas define os mates de movimento (revolute, slider, etc.) entre esses blocos.

<Aside type="note">
Uma montagem rígida, ao ser inserida em outra, é tratada como um corpo único sem necessidade de recalcular relações internas. Isso acelera imensamente o tempo de carregamento das montagens superiores. No guia de [boas práticas de montagem](../assembly-setup/), você aprenderá a usar o cubo de origem (*origin cube*) para fixações paramétricas instantâneas.
</Aside>

Por exemplo, em um elevador de múltiplos estágios, pode-se criar uma submontagem rígida para o estágio estático, uma para o primeiro estágio e uma para o carrinho (carriage). A montagem superior do elevador apenas une essas três submontagens usando relações deslizantes (*slider mates*).

O Intake Slapdown da Etapa 2C é um subsistema composto por uma parte estática e uma parte articulada (pivô). Estruturalmente, ele contém um Part Studio, uma montagem estática para as redutoras e base do pivô, uma montagem rígida para os braços móveis e roletes, e uma montagem superior combinando ambas com uma junta rotativa (*revolute mate*).
