---
title: Boas Práticas de Esboço de Layout (Layout Sketch)
description: As melhores práticas a seguir ao criar esboços mestres de layout e arquitetura no Onshape.
---

Um esboço de layout principal (Layout Sketch ou Master Sketch) é uma série de esboços que captura as dimensões críticas de cada mecanismo, as interações com os elementos de campo e as restrições de volume do robô (perímetro e limites de expansão). Esses esboços mestres são então inseridos (via *Derived*) no Part Studio de cada mecanismo, e os componentes individuais são modelados diretamente sobre essa geometria de referência. Isso viabiliza um fluxo de integração muito mais eficiente na metodologia top-down.

| **Sempre Incluir**                                                           | **Às Vezes Incluir**                                | **Nunca Incluir**                                           |
|:----------------------------------------------------------------------------|:----------------------------------------------------|:------------------------------------------------------------|
| Dimensões do chassi / drivebase                                             | Engrenagens                                         | Detalhes específicos de peças (formato exato de chapas)     |
| Posições das rodas e roletes do manipulador baseadas em prototipagem        | Correias                                            | Gussets                                                     |
| Elementos da arena e limites de expansão de regras                          | Correntes                                           | Furos de montagem e parafusos                               |
| Trajetórias de movimento dos mecanismos                                     | Posicionamento de motores                           |                                                             |
| Trajetória e caminho da peça de jogo (gamepiece)                            |                                                     |                                                             |

Esta não é uma lista definitiva; os detalhes podem variar dependendo da equipe e da arquitetura do robô. Novos níveis de detalhe podem ser adicionados ou removidos conforme o projeto amadurece.

Todas as medidas críticas que definem a geometria do robô residem no Part Studio de layout. Dessa forma, qualquer cota pode ser visualizada e ajustada em conjunto, ao invés de exigir a edição manual de peça por peça em cada subsistema para tentar fazer tudo se encaixar na montagem final.

Os esboços principais sempre começam pelo drivetrain, para-choques (bumpers), configuração inicial de partida e perímetros máximos de expansão. Em seguida, desenham-se os elementos do campo. O alinhamento mecânico encostando os para-choques diretamente nos elementos da arena é uma excelente estratégia para pontuar com alta repetibilidade, sem depender de sensores ou códigos complexos.

<Aside type="tip">
Logo após o Kickoff, crie um Part Studio contendo o chassi básico, os limites de expansão e os elementos da arena. Faça cópias desse arquivo para explorar e comparar rapidamente diferentes arquiteturas de robô antes de escolher a definitiva.
</Aside>

O robô deve ser projetado especificamente para interagir com os elementos do campo e as peças de jogo. No esboço de layout, isso significa tornar cada cota intencional e justificada — seja pelas regras da arena, limites de tamanho ou pela relação entre mecanismos adjacentes.

<Aside type="example">
O curso e a altura de um elevador devem ser determinados pelas posições inicial e final necessárias para o manipulador recolher ou pontuar a peça de jogo no campo.
</Aside>

<Aside type="tip">
Você pode traçar arcos ou círculos de construção que representem o raio de rotação de um mecanismo articulado e posicionar outros mecanismos com folga segura em relação a essa trajetória para evitar colisões internas.
</Aside>

Para que o esboço mestre seja realmente eficaz, a organização é fundamental:

- Mantenha múltiplos sketches, geralmente um para cada subsistema, dentro do mesmo Part Studio de layout. Mantenha cada ideia separada!
- Nomeie cada esboço de forma clara e descritiva
- Você também pode aplicar [cores distintas a cada sketch](https://www.youtube.com/watch?v=ZG_gVeGdI5c) para facilitar a visualização
- Desenhe todos os estados críticos possíveis de cada mecanismo móvel (recolhido, pontuando baixo, pontuando alto, etc.)
