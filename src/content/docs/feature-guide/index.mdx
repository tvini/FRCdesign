Existem vários recursos interativos no site que tornam o aprendizado muito mais dinâmico e visual. Abaixo estão explicadas as principais ferramentas para que você possa tirar o melhor proveito do material.

## Recursos Globais

- [Links](/learning-course/) aparecem destacados em verde.
- Clicar em qualquer imagem abre uma visualização ampliada (lightbox) com legenda. Pressione a tecla `Esc` para fechar.
- O site possui um [glossário](/resources/glossary/) com termos técnicos e siglas de FRC. Sempre que uma palavra do glossário aparecer no texto, ela terá um sublinhado pontilhado. Basta passar o cursor sobre ela para ver a definição imediata (ex: COTS, OTB).
- Algumas informações detalhadas ficam recolhidas em caixas expansíveis para manter as páginas limpas:
