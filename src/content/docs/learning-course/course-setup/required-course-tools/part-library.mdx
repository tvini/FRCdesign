## Configurando o FRCDesignApp

O FRCDesignApp é uma extensão oficial para o Onshape que permite utilizar uma ampla biblioteca de componentes COTS essenciais ao projetar robôs para a FRC.

<Aside type="tip">
O FRCDesignApp é o aplicativo/plugin que permite inserir peças nos seus documentos, enquanto o FRCDesignLib é a coleção propriamente dita dos modelos CAD. O FRCDesignApp é atualizado periodicamente para incluir novas ferramentas e bibliotecas.
</Aside>

Para instalar, acesse a [página do FRCDesignApp](https://appstore.onshape.com/apps/Manufacturers%20Models/2ZT7X5D646R3LM3ZND7LGBTYRVM4SVH6CDDGM6I=/description) na App Store do Onshape.

Clique em "Subscribe" e, em seguida, em "Get for Free". O aplicativo será adicionado automaticamente à sua conta do Onshape.

<Aside type="note" title="Observações">
- Após assinar o app, o painel de inserção do FRCDesignLib só aparecerá nos documentos já abertos se você recarregar a aba do navegador (F5). Isso só é necessário na primeira vez.
- Pode ser necessário autorizar o aplicativo e aceitar as permissões no primeiro uso.
</Aside>
