## Layout Sketches

Os layout sketches principais de um elevador geralmente começam por uma vista lateral totalmente estendida, para que você possa definir a altura total com base nos limites de extensão máxima da regra do jogo e nas posições inicial e final necessárias para o seu mecanismo final (end effector).

Embora este elevador de estudo não esteja inserido no contexto de um jogo específico, ainda é altamente recomendado seguir esse mesmo fluxo de trabalho iniciando pelo sketch lateral, que conterá as variáveis geométricas mais críticas.

Siga as orientações nos slides para criar os layout sketches do seu elevador.

<Slides>
  ![Sketch frontal dos tubos do elevador](../img/2d/master-sketch.webp)
  Uma visão limpa do sketch frontal dos tubos estruturais do elevador.

  ![Sketch lateral estendido](../img/2d/elevatorSideExtendedSketch.webp)
  Como prática preparatória para o Stage 3, começaremos definindo a posição do elevador em relação à vista lateral do chassi. Use retângulos para representar o tubo 2x2 e o comprimento dos estágios. Adicione retângulos para representar os tubos inferiores de cada estágio e do carrinho (carriage).

  ![Sketch lateral retraído](../img/2d/elevatorSideRetractedSketch.webp)
  Fique à vontade para desenhar um sketch lateral na posição retraída (restringindo-o geometricamente ao primeiro sketch lateral) para validar folgas e empacotamento quando o elevador estiver abaixado. Isso é especialmente útil no projeto de um robô completo.

  ![Sketch frontal](../img/2d/elevatorFrontSketch.webp)
  Agora adicione o sketch frontal para definir todos os tubos dos estágios do elevador, a largura do conjunto e as distâncias laterais entre os estágios.
</Slides>

<Aside type="tip">
Em vez de desenhar vistas separadas de "estendido" e "retraído", você pode separar os estágios em seus próprios sketches individuais para "animar" o movimento linear dentro do sketch. Você pode utilizar configurações para alternar entre as posições.
</Aside>
