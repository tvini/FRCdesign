## Montagem (Assembly)

Como este subsistema possui múltiplas partes móveis que deslizam linearmente, assim como no pivô em dead axle e no intake slapdown, devemos criar submontagens rígidas separadas para cada estágio.

### Montagem do Estágio Base (Base Stage Assembly)

Crie uma montagem para as partes estáticas e siga o processo padrão para inseri-las e criar um conjunto rígido (Origin Cube, Group Mate, Fasten Mate na origem). Adicione o restante das peças duplicando peças existentes, inserindo da FRCDesignLib e do Standard Content, utilizando Replicate e padrões sempre que possível.

<ContentFigure src="../img/2d/frameSubassembly.webp" alt="Montagem do estágio base concluída" />

### Montagem do Primeiro Estágio (First Stage Assembly)

Repita o mesmo procedimento para a submontagem do primeiro estágio intermediário móvel.

<ContentFigure src="../img/2d/stage1Subassembly.webp" alt="Montagem do primeiro estágio concluída" />

### Montagem do Carrinho (Carriage Assembly)

E, finalmente, faça o mesmo para a submontagem do carrinho móvel (carriage).

<ContentFigure src="../img/2d/carriageSubassembly.webp" alt="Montagem do carrinho concluída" />

### Montagem de Nível Superior (Top Level Assembly)

Agora crie a montagem de nível superior, insira as submontagens (fixando o Origin Cube da montagem estática na origem da montagem) e use os mate connectors de referência dos Origin Cubes das submontagens para criar mates do tipo `Slider` com limites de curso para definir o movimento linear do elevador.

<ContentFigure src="../img/2d/elevatorTopLevel.webp" alt="Montagem Finalizada de Nível Superior do Elevador" />

Por se tratar de um elevador em cascata, você pode usar a ferramenta de montagem `Linear Relation` entre os dois slider mates com uma relação de 1:1, vinculando o movimento linear dos estágios exatamente da mesma forma como eles se comportam na vida real.
