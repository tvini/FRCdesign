## Sistema de Acionamento (Drive System)

Elevadores necessitam de motores com torque e redução calculados para acioná-los. Uma vez planejado o trajeto do cabeamento (rigging), você pode definir onde posicionar os motores e as caixas de redução para movimentar o primeiro estágio do elevador.

<ContentFigure src="../img/2d/gearbox.webp" alt="Detalhe do sistema de acionamento do elevador" width="50%"/>

### Projeto de Referência

O projeto de referência utiliza um circuito de corrente vertical acoplado ao pente de fixação TTB (chain comb) e motores REV NEO acoplados a redutores planetários MAXPlanetary.
