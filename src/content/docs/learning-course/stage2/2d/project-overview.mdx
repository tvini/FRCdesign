## Visão Geral do Projeto

Como elevadores são essencialmente mecanismos para transportar outros subsistemas linearmente no espaço, este projeto se assemelha ao pivô em dead axle: será projetado de forma independente para que você aprenda a lógica de modelagem e conheça seus componentes. Você praticará o projeto de elevadores integrados ao robô completo no Stage 3.
