## Eixos Zumbi (Zombie Axles)

Como a articulação do braço é um dead axle (eixo morto), o eixo central não gira junto com o braço. Isso significa que podemos aproveitar esse mesmo eixo como um live axle concêntrico para girar uma polia intermediária que transfere potência para os roletes da ponta. Isso é chamado de **"Zombie Axle"** (Eixo Zumbi), pois o eixo de articulação atua simultaneamente como dead axle estrutural para o pivô e como live axle rotativo para acionar os roletes.

Essa estratégia engenhosa permite que o motor dos roletes permaneça montado na base fixa do robô, o que reduz substancialmente o peso na ponta do braço móvel e protege o motor contra colisões diretas.
