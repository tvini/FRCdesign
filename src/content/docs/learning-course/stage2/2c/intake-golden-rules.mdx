## Regras de Ouro de Intakes (Intake Golden Rules)

Existem muitos materiais excelentes sobre como projetar intakes de alto desempenho. Andrew Torrance, da equipe 254 (The Cheesy Poofs), formulou [uma lista clássica de regras de ouro para intakes de roletes](https://www.chiefdelphi.com/t/besiktas-rsports-9483-2023-off-season-build-blog/440340/15).

### As Regras

- A velocidade periférica (surface speed) dos roletes do intake deve ser pelo menos o **dobro** da velocidade máxima de deslocamento do robô (2x robot speed).
- Maximize a aderência com a peça de jogo através de todos os meios mecânicos possíveis para otimizar a transferência de energia e, portanto, a velocidade e confiabilidade da coleta ("touch it, own it").
- Se a peça de jogo for macia/flexível, use roletes rígidos; se a peça for dura/rígida, use roletes flexíveis ou com conformidade (compliant).
- Maximize a largura e a área de captura do intake para facilitar a coleta tanto no período autônomo quanto no teleoperado sem precisar de alinhamento perfeito.
- Intakes precisam ser extremamente robustos, pois operam frequentemente estendidos para fora do perímetro dos bumpers, sujeitos a pancadas fortes contra paredes e outros robôs.
- Utilize sensores (ópticos, laser ou de corrente) para detectar a presença e a posse imediata das peças de jogo.

### Projeto de Referência

O projeto de referência segue rigorosamente todas as regras de ouro, exceto pela fixação de sensores, já que a modelagem de suportes 3D para sensores está fora do escopo geométrico deste projeto básico.
