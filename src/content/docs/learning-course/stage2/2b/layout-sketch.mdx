## Layout Sketch

O layout sketch para este mecanismo é bastante direto, pois utiliza redutores planetários MAXPlanetary para a redução primária.

1. Use o Featurescript Origin Cube para inserir o Origin Cube.
2. Dimensione o tubo transversal da estrutura.
3. Posicione o ponto do pivô e a posição do sprocket motriz acima da barra transversal. Dimensione uma linha de construção entre eles com uma distância que forneça comprimento de corrente reto suficiente para instalar um esticador em linha.
4. Crie círculos de construção para representar os círculos primitivos (pitch circles) de ambos os sprockets e o diâmetro externo do motor.
