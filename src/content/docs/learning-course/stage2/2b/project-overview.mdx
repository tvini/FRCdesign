## Visão Geral do Projeto

Você projetará um pivô articulado simples em dead axle. Embora este braço não seja projetado para um jogo específico, ele ensinará conceitos essenciais aplicáveis a qualquer mecanismo rotativo ou braço na FRC.

Os requisitos do projeto são os seguintes:

- **Gearbox:** Utilizar caixas de redução planetárias MAXPlanetary.
- **Corrente:** Utilizar corrente #25 com uma grande redução no sprocket de saída.
- **Eixo:** Utilizar tubo redondo de 7/8 polegadas para o dead axle, assegurando suporte mecânico apropriado.
