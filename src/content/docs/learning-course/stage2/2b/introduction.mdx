## Pivô em Dead Axle (Dead Axle Pivot)

Você projetará um pivô articulado simples em dead axle (eixo fixo/morto). Embora este braço não seja voltado para uma temporada específica, ele ensinará conceitos fundamentais aplicáveis a qualquer mecanismo rotativo ou braço articulado na FRC.

Os requisitos do projeto são os seguintes:

- **Gearbox:** Utilizar redutores planetários MAXPlanetary.
- **Corrente:** Utilizar corrente #25 com uma grande redução no sprocket final.
- **Eixo:** Utilizar tubo redondo de 7/8" de diâmetro para o dead axle e garantir apoio estrutural adequado.
