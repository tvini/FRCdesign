## Visão Geral do Projeto

Até agora, você criou os layout sketches principais e modelou a estrutura de tubos e o bellypan básico do chassi.

<ContentFigure src="../img/1d/drivetrain-assembly.webp" alt="Swerve Drivebase do Stage 1D" width="60%">Swerve Drivebase do Stage 1D</ContentFigure>

**Para concluir o chassi, você utilizará o conteúdo das páginas a seguir para adicionar estes detalhes:**

1. **Fixação da Bateria (Battery Mounting):** Todo robô precisa de bateria e, embora sua posição possa variar dependendo dos outros mecanismos presentes, ela deve ser sempre posicionada o mais baixo possível para maximizar a estabilidade do robô.

2. **Montagem dos Componentes Eletrônicos (Electronics Mounting):** Espaço adequado deve ser reservado no robô para permitir uma fiação limpa e segura. Tipicamente, os componentes eletrônicos são fixados sobre o bellypan.

3. **Alívio de Peso do Bellypan (Pocketing):** Esta etapa é opcional. Algumas equipes preferem criar recortes e padrões de alívio no bellypan para diminuir o peso e facilitar a passagem de abraçadeiras e cabos elétricos. No entanto, aliviar o bellypan pode aumentar bastante o tempo de usinagem na CNC.

4. **Bumpers e Suportes de Bumper:** Embora as regras de bumpers possam variar a cada temporada, eles são quase sempre obrigatórios para proteger seu robô e os outros contra colisões intensas. Projetar bumpers fáceis e rápidos de colocar e retirar é uma enorme melhoria na qualidade de vida da equipe durante as competições.

<Aside type="note">
Mesmo que os três primeiros detalhes não referenciem diretamente o layout sketch, eles referenciam peças que derivam do layout sketch (a estrutura do chassi) e, portanto, se atualizarão de forma correspondente caso mudanças sejam feitas.
</Aside>

Embora a implementação exata para cada um desses detalhes varie de equipe para equipe e de acordo com a arquitetura geral do robô, um modelo de referência para o Stage 1E é fornecido.
