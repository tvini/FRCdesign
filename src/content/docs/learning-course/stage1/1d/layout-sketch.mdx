## Layout Sketches do Drivetrain

Para começar, você criará um layout sketch do chassi (drivetrain). Ele ditará as dimensões e as posições dos tubos estruturais. O layout será desenhado a partir das vistas lateral e superior do drivetrain. Para o seu chassi swerve, usaremos a dimensão de 26" x 26".

### Instruções

Comece **criando um novo Documento no Onshape chamado `Stage 1D Robot`** e, dentro dele, **um novo part studio chamado `Main Layout Sketch`**. Em seguida, use o Featurescript `Origin Cube` para criar o cubo de origem. **Siga as instruções nos slides** para concluir o layout sketch.

<Slides>
  ![](../img/1d/layout-sketches/layout-0.webp)
  O layout sketch final.

  ![](../img/1d/layout-sketches/layout-1.webp)
  Desenhe o perfil lateral do drivetrain no plano Right. Posicionamos o tubo a 1,75" do chão, que é a distância do chão até a face inferior do tubo para os módulos SDS MK4i. Em seguida, desenhe o retângulo de folga da roda (wheel clearance box), que representa a área ocupada pela roda. Para os módulos MK4i, essa caixa tem 4,625" de largura.

  ![](https://www.youtube.com/embed/fE7Zhv1DYt0?controls=1&rel=0&showinfo=0&vq=hd1080)
  Crie o layout sketch superior utilizando o mate connector inferior sobre a linha vertical do layout lateral. Utilizar mate connectors gerados automaticamente como planos de esboço é uma técnica extremamente útil. Pressione o botão "Top" no cubo de visualização (view cube) para obter a vista superior.

  ![](https://www.youtube.com/embed/HfoS699wNPc?controls=1&rel=0&showinfo=0&vq=hd1080)
  Esboce o contorno superior do chassi. Faça o retângulo ser um quadrado e defina o comprimento dos lados como igual ao comprimento do tubo do layout lateral. Isso assegura que o tamanho do layout superior sempre acompanhe o layout lateral, tornando o projeto paramétrico. Observe que o sketch fica totalmente definido (linhas pretas) mesmo sem cotas numéricas explícitas.

  ![](../img/1d/layout-sketches/layout-4.webp)
  Para desenhar os tubos, trace um quadrado 1" menor do que o quadrado anterior. Isso representará os quatro tubos 2"x1" que formam o perímetro externo. Em seguida, desenhe o perfil superior do tubo 2"x2". No canto inferior direito, trace duas linhas, cada uma com offset de 4,25" a partir da aresta externa. Esse é o deslocamento necessário para os módulos MK4i (outros modelos de swerve exigirão medidas diferentes).

  ![](https://www.youtube.com/embed/5st3BiDfGdY?controls=1&rel=0&showinfo=0&vq=hd1080)
  Para aplicar o recorte nos quatro cantos dos tubos, usamos a ferramenta de sketch Circular Pattern para copiar as linhas para os quatro cantos. Em um padrão circular, definimos primeiro o número de instâncias e, em seguida, o eixo de rotação.

  ![](../img/1d/layout-sketches/layout-0.webp)
  Por fim, nomeie seus sketches e organize-os em pastas na árvore de features. Seus sketches devem estar todos totalmente definidos (totalmente pretos).
</Slides>

Como explicado anteriormente, esse método de modelagem top-down é extremamente poderoso, pois permite centralizar as variáveis dimensionais mais críticas em um único local. No entanto, tome cuidado para não sobrecarregar os layout sketches com detalhes excessivos. Você praticará layout sketches ao longo de todo o Stage 2 e os usará no Stage 3 junto com práticas de múltiplos documentos para projetar um robô completo.
