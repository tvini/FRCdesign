## Introdução

Até aqui, você praticou os fundamentos de CAD através de cursos e exercícios relevantes para a FRC, mas ainda não desenvolveu algo dentro do contexto maior de um robô completo. Nesta etapa, você mergulhará de vez no projeto de um robô real. Neste projeto, você projetará um chassi swerve (swerve drivebase) enquanto aprende um fluxo de trabalho de projeto que será aplicado em todos os projetos futuros.

1. Aprender os fundamentos do projeto top-down e de layout sketches
2. Modelar um chassi swerve utilizando módulos swerve COTS
3. Criar uma montagem de nível superior (top-level assembly) e inserir um mecanismo pré-modelado (o elevador e manipulador de 2023 da equipe 1678)

Mesmo que você já tenha modelado um drivetrain no passado, este guia serve como uma excelente introdução à metodologia de projeto **top-down** orientada por layout sketches.
