## Resumo

Parabéns por concluir o Stage 1D! Continue com o ótimo trabalho!

Aqui está um resumo rápido do que você conquistou no 1D:

* Aprendeu sobre a metodologia de projeto top-down de robôs e layout sketches
* Aprendeu a usar a feature Derived para orientar part studios usando layout sketches
* Aprendeu a usar o Origin Cube para unir montagens de nível superior (top level assemblies)
* Aprendeu a modelar um chassi swerve simples

No Stage 1E, você continuará detalhando o chassi swerve recém-criado e praticará o fluxo de trabalho de adição de componentes a um subsistema.

Não se esqueça de preencher nosso rápido [**formulário de feedback**](https://forms.gle/qykF1UoxiymAEGWc8) do 1D para que possamos coletar dados e saber como continuar aprimorando o site!
