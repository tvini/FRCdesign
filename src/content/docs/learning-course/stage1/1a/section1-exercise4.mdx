## Exercício 4: Desenhando a Estrutura do Chassi

Agora que você já desenhou peças individuais, é hora de criar o sketch da estrutura completa de um chassi de tração.

<ContentFigure src="../img/1a/exercise4-dt-frame.webp" alt="Estrutura Final">Estrutura Final</ContentFigure>

No documento de exercícios que você duplicou, abra o Part Studio do Exercício 4.

Assista ao vídeo abaixo e acompanhe as instruções para criar o sketch do chassi enquanto pratica diversas técnicas de modelagem de peças em contexto:

<ContentFigure src="lDW9H3a70aM">Criando a estrutura do chassi</ContentFigure>

Seu objetivo é esboçar e extrudar os retângulos mostrados abaixo e, em seguida, transformá-los em tubos furados com o `Tube Converter`.

<Aside type="tip">
Lembre-se de **espelhar (mirror) ou criar padrões geométricos** usando linhas de construção — nunca desenhe ambos os lados manualmente do zero!
</Aside>

<ContentFigure src="../img/1a/exercise4-drivetrain-sketch.webp" alt="Sketch do Chassi">Sketch do Chassi</ContentFigure>

<Aside type="caution" title="Pontos Importantes para o Sketch">

- Espelhe as geometrias através dos eixos X e Y.
- Evite o excesso de cotas (overdimensioning) — use restrições de simetria e igualdade sempre que possível.
- Garanta que as vigas transversais também estejam espelhadas simetricamente.
- Use a Origem como ponto central de referência para toda a geometria.

</Aside>

Se o seu sketch estiver totalmente restringido (todas as linhas ficarem pretas), parabéns: você fez da maneira correta! Agora **utilize o `Extrude Individual` e o `Tube Converter` para transformar o sketch nos tubos estruturais do chassi.**

### Finalização

1. **Adicione as vigas transversais** como fez no exercício anterior **para completar os tubos do chassi.**
2. **Confira minuciosamente** se nenhuma peça se fundiu incorretamente com outra.
3. Utilize o ponto da origem e o plano superior (Top Plane) para validar o alinhamento.
4. Verifique se os vãos dos tubos deixam o espaço livre correto para o encaixe dos módulos de tração.
