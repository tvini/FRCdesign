Neste exercício, você extrudará quatro retângulos por duas polegadas simetricamente — e os converterá em tubos.

### Ficou um pouco estranho?

Se você seguiu as instruções e usou uma única extrusão convencional, os quatro retângulos provavelmente se fundiram em um único grande bloco sólido contínuo.
No mundo real, não queremos tubos fundidos entre si dessa forma.

> Você consegue deduzir como extrudá-los **individualmente** para que permaneçam como peças separadas?

Se precisar recomeçar, assista a este vídeo rápido mostrando como excluir operações com erro:

<ContentFigure src="2Jzb1Xr6NBE">Como excluir operações de extrusão</ContentFigure>

---

### Consertou sua extrusão?

Fazer quatro operações de extrusão manuais separadas é demorado e ineficiente. Existe uma solução muito melhor!

- Exclua as extrusões antigas.
- Use o FeatureScript `Extrude Individual` que você instalou nas [ferramentas obrigatórias](/learning-course/course-setup/required-course-tools/featurescripts).
- (Pressione `Alt + C` e digite "extrude individual" se precisar localizá-lo rapidamente.)

Essa ferramenta permite extrudar múltiplas regiões de sketch como peças totalmente independentes em uma única etapa inteligente.

Além disso, ativando a opção "Symmetric" dentro do Extrude Individual, a extrusão se expande igualmente para ambos os lados do plano.

<ContentFigure src="../img/1a/extrude-individual.webp" alt="Utilizando a opção Symmetric no Extrude Individual.">Utilizando a opção "Symmetric" dentro do Extrude Individual.</ContentFigure>

## Exercício 3.1: Fundamentos de Sketching (Esboços)

No exercício anterior, você extrudou um sketch pronto. Agora é hora de **você mesmo criar o sketch do zero**.

Ao desenhar no sketch, usamos retângulos para representar as seções dos tubos em 2D, e aplicamos **dimensões (cotas)** e **restrições geométricas (constraints)** para travar tudo com precisão matemática.

Acompanhe o vídeo abaixo para praticar os conceitos fundamentais de sketch no Onshape:

<ContentFigure src="ftbpbvuZklc">Fundamentos de sketch no Onshape</ContentFigure>

<Aside type="tip" title="Pontos-Chave de Sketching">

- **Dimensões (Dimension - atalho D)** controlam distâncias e tamanhos (ex: definir um retângulo com exatas 5 polegadas de largura).
- **Restrições geométricas (Constraints)** definem comportamentos e relações (como fixar a aresta de um tubo alinhada ou colinear à outra).
- **Linhas amarelas pontilhadas** indicam inferências automáticas do Onshape — aproveite-as!
- **A Origem (Origin)** é a sua âncora no espaço. Sempre amarre seus sketches principais à origem.
- **Azul indica indefinição** — linhas azuis têm graus de liberdade soltos. Seu objetivo é sempre deixar **tudo 100% preto**.
- **Menos é mais** — utilize o menor número possível de cotas dimensionais, aproveitando simetria, igualdade e alinhamentos para definir o modelo.

</Aside>

## Exercício 3.2: Adicionando Vigas ao Chassi

<ContentFigure src="../img/1a/3-2-sketch.webp" alt="Edite este sketch">Edite este sketch</ContentFigure>

Agora vamos aplicar esse conhecimento no chassi do robô.

Abra o sketch `Top Tube Sketch` no Part Studio do Exercício 3.2 e **adicione duas vigas transversais** com **8 polegadas de distância entre si**.

<Aside type="tip">
Dê um duplo clique no sketch na árvore de operações (feature list) para editá-lo.
</Aside>

Desenhe você mesmo os novos retângulos das vigas. Adicione apenas **uma única nova cota dimensional** em todo o sketch!

Os únicos números que devem aparecer cotados no sketch são:

- 4.25" (vão livre para os módulos swerve)
- 1" (largura do perfil do tubo)
- 8" (distância entre as vigas transversais)
