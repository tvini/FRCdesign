## Exercício 2: Montagem do Chassi Swerve

Agora que você aprendeu a manusear rebites em uma montagem, vamos aplicá-los em escala no chassi de tração.

Para começar, abra a aba "S3 Exercise 2" dentro da pasta "Section 3" na sua cópia do documento.

**Acompanhe o vídeo abaixo** para realizar o exercício:

<ContentFigure src="UZHMD1GFG44">Montagem do chassi swerve</ContentFigure>

<Aside type="tip">
A ferramenta de replicação rápida (`Replicate`) é apresentada neste exercício. Você pode utilizá-la para duplicar automaticamente componentes repetitivos (como rebites, parafusos ou rolamentos) em todos os furos de geometria ou diâmetro idêntico de uma só vez.
</Aside>

1. Copie, cole e fixe com mates os gussets restantes na estrutura do chassi.
2. Insira rebites da biblioteca FRCDesignLib e preencha os gussets utilizando a ferramenta **Replicate**.
3. Insira os módulos de tração **MK4i** (mantenha a configuração padrão sugerida).
4. Fixe os módulos swerve nos cantos do chassi. **Não se preocupe com parafusos nesta etapa**.

<Aside type="tip">
Experimente utilizar a ferramenta de padrão circular em montagem (`Circular Pattern`) para replicar um módulo swerve para os quatro cantos do chassi de uma única vez.
</Aside>

Assim que os gussets, rebites e módulos swerve estiverem montados, avance para o próximo exercício.
