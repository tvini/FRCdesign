## Exercício 2: Chapa de Junção (Gusset)

No exercício anterior, modelamos uma chapa isolada no espaço. Neste exercício, você criará um gusset real para unir dois tubos de um chassi, combinando as ferramentas já aprendidas com um comando novo.

Para começar, abra o Part Studio "Exercise 2: Gussets" dentro da pasta "Section 2" no seu documento de exercícios.

Sua tarefa é **criar um gusset simples para o chassi fornecido**, **repetindo o fluxo de modelagem de chapas** praticado no exercício anterior. Os furos para este gusset serão copiados diretamente dos furos dos tubos com a ferramenta `Use / Project` (atalho `U`):

<Aside type="caution">
**Não utilize o FeatureScript Gusset Generator!** Este exercício tem como objetivo fixar o fluxo manual correto de criação de chapas. FeatureScripts prontos de gusset costumam quebrar facilmente quando a geometria dos tubos muda e não oferecem flexibilidade de contorno, não sendo recomendados para design paramétrico robusto.
</Aside>

<Aside type="tip" title="Lembre-se...">

- O atalho de teclado para a ferramenta `Use / Project` é a tecla `U`.
- Arcos de contorno só devem ser posicionados nos cantos externos da chapa, e não ao redor de cada furo intermediário.

</Aside>

### Concluiu?

Experimente **recriar esse gusset** (ou criar um com formato diferente, como em formato de T ou L) para uma **outra quina do chassi**!

Assim que terminar os **dois gussets**, avance para o próximo exercício.
