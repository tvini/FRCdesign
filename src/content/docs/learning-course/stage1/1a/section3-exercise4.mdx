## Exercício 4: Montagem Completa do Chassi

Para começar, abra a aba de montagem "S3 Exercise 4" dentro da pasta "Section 3" na sua cópia do documento de exercícios.

**Acompanhe o vídeo abaixo** para realizar o exercício:

<ContentFigure src="1HXdMi8PiXw">Montagem completa do chassi com parafusos</ContentFigure>

1. Insira o Part Studio do Exercício 3 da Seção 3 (com o gusset que você modelou).
2. Agrupe todos os componentes da estrutura utilizando a ferramenta **Group**.
3. Insira o módulo MK4i (caso ainda não esteja inserido).
4. Fixe os módulos nos cantos do chassi com conectores de montagem Fastened.
5. Insira os parafusos pela biblioteca FRCDesignLib (parafusos Allen cilíndricos #10-32 x 2.5" - Socket Head Cap Screws / SHCS).
6. Meça a distância entre as faces para determinar o comprimento correto do parafuso, arredondando para cima para o tamanho comercial padrão mais próximo.
7. Fixe os parafusos na posição correta.
8. Utilize a ferramenta **Replicate** (configurada para `Match edges on a plane`) para duplicar os parafusos em todos os módulos automaticamente.

<Aside type="tip" title="Furos com Rosca (Tapped Holes)">
Os furos na placa superior de fixação do módulo swerve são roscados diretamente no alumínio (tapped). Isso significa que não é necessário adicionar porcas nos parafusos, pois a própria placa funciona como a rosca fêmea.
</Aside>

---

Assim que concluir a montagem do chassi com todos os parafusos e módulos, avance para o último exercício do 1A, onde você integrará tudo o que aprendeu até aqui!
