## Exercício 2: Gearbox de Dois Estágios

Neste exercício, você modelará e montará uma gearbox de dois estágios. O objetivo deste exercício é praticar a modelagem de caixas de redução mais avançadas. Você também aprenderá a usar o Featurescript [`Part Lighten`](https://cad.onshape.com/documents/028ca8fb10baf53e1f6fce96/w/b1250a450d0ba88f0a8b1811/e/a8b9e45297aac9f5688c871d), utilizado para aliviar peso em peças (pocketing/alívio).

<Aside type="caution">
Embora esta etapa peça para você aliviar as placas ao terminar o part studio, isso não é a melhor prática geral. Ao modelar um mecanismo completo ou o robô inteiro, você deve **esperar para aliviar as placas somente depois que todas as revisões de projeto e alterações tiverem sido feitas no mecanismo ou robô**. Caso contrário, você acabará perdendo tempo consertando os alívios toda vez que a placa ou mecanismo mudar.
</Aside>

### Instruções do Part Studio
**Navegue até a aba "Exercise #2 Part Studio"** no seu documento copiado e **siga as instruções nos slides** para concluir o part studio.

<Slides>
  ![](../img/1b/exercises/exercise2/parts-0.webp)
  Part Studio finalizado.

  ![](../img/1b/exercises/exercise2/parts-1a.webp)
  Crie o layout sketch da gearbox. Comece desenhando o 2º estágio, que é uma engrenagem de 20T para uma de 50T.

  ![](../img/1b/exercises/exercise2/parts-1b.webp)
  Desenhe o primeiro estágio, que é o pinhão do motor de 12T para uma engrenagem de 50T.

  ![](../img/1b/exercises/exercise2/parts-1c.webp)
  Desenhe o contorno dos motores como um círculo de 2,5" de diâmetro. Este é o layout sketch concluído para a gearbox.

  ![](../img/1b/exercises/exercise2/parts-2.webp)
  Crie um novo sketch para desenhar o perfil da placa. Tendo o layout sketch como referência, adicione os furos de rolamento, que são furos de 1,125" de diâmetro, bem como os furos do boss do motor, que são de 1,25". Adicione também os furos de montagem do motor. Você pode utilizar a ferramenta Mirror no sketch para espelhar a geometria do lado esquerdo para o lado direito.

  ![](../img/1b/exercises/exercise2/parts-3.webp)
  Faça a extrusão da placa com 1/4" de espessura.

  ![](../img/1b/exercises/exercise2/parts-4.webp)
  Use o Featurescript Robot Spacer para criar o espaçador da gearbox.

  ![](https://www.youtube.com/embed/hgIBEwiXtEc)
  Use o Featurescript Robot Shaft para criar o eixo do primeiro estágio.

  ![](../img/1b/exercises/exercise2/parts-6.webp)
  Use o Featurescript Robot Shaft para criar o eixo de saída.

  ![](../img/1b/exercises/exercise2/parts-7.webp)
  Crie um sketch na face da placa e desenhe as linhas para as nervuras de alívio (pocketing ribs).

  ![](https://www.youtube.com/embed/P3Snm7U0M_g)
  Use o Featurescript Part Lighten para aliviar a placa selecionando as nervuras criadas pelo sketch anterior.

  ![](../img/1b/exercises/exercise2/parts-0.webp)
  Part Studio concluído. Nomeie os sketches, features e peças. Defina o nome, material (6061 Aluminum) e aparência das placas e espaçadores.
</Slides>

### Instruções de Montagem (Assembly)

**Em seguida, navegue até a aba "Exercise #2 Assembly"** no seu documento copiado e **siga as instruções nos slides** para concluir este exercício.

<Slides>
  ![](../img/1b/exercises/exercise2/assy-0.webp)
  Montagem final.

  ![](https://www.youtube.com/embed/iz8vTGKxy7M)
  Insira o part studio na montagem e fixe apenas a placa da gearbox. Monte o espaçador na placa. Em seguida, use a ferramenta Replicate para replicar o espaçador e seu respectivo mate nas outras posições de espaçador.

  ![](../img/1b/exercises/exercise2/assy-2.webp)
  Copie a placa da gearbox e monte-a na posição correta.

  ![](https://www.youtube.com/embed/q-Ca99yyEDY)
  Monte os rolamentos e os eixos usando peças da FRCDesignLib.

  ![](https://www.youtube.com/embed/pEOxmxGMHPk)
  Monte o motor e o pinhão do motor usando peças da FRCDesignLib.

  ![](https://www.youtube.com/embed/fMX8k8QicGQ)
  Monte os espaçadores de eixo e as engrenagens usando peças da FRCDesignLib.

  ![](https://www.youtube.com/embed/VJy8NSFISa0)
  Monte os parafusos de retenção do eixo, parafusos do motor, parafusos da gearbox e porcas usando peças da FRCDesignLib.

  ![](../img/1b/exercises/exercise2/assy-0.webp)
  Montagem concluída. Certifique-se de organizar suas peças em pastas e nomear suas features de replicação.
</Slides>
